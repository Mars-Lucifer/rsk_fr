# Этап «Я» 🟢 собран

Индивидуальная часть конкурса: 8 видеоуроков, к каждому — задание в тренажёре
МАЯК ОКО. Уроки открываются по очереди: следующий доступен, когда закрыт
предыдущий.

Обновлено: 06.08.2026

## 1. Состав этапа

| № | Урок | Формат задания |
|---|------|----------------|
| 1 | Вводный урок | Старт |
| 2 | Текст | Текст |
| 3 | Аудио | Аудио |
| 4 | Изображение | Изображение |
| 5 | Интерактив | Интерактив |

форматов контента.

## 2. Поток участника

```
регистрация → письмо → подтверждение → вход
   └─ сразу попадает в раздел «Конкурс» (/cours)
        └─ 8 карточек сеткой 4×2, доступен только следующий урок
             └─ «К уроку» → тренажёр открывается на этом уроке
                  ├─ лесенка уроков в шапке, переключение без перезагрузки
                  ├─ карточка задания + «Задание целиком» в попапе
                  ├─ видеоурок (обложка, плеер по клику)
                  ├─ поля МАЯК ОКО и генерация промта — как обычно
                  └─ ответ: текст или файл до 20 МБ
                       └─ «Завершить задание» → урок закрыт, открыт следующий
```

После восьмого урока — возврат к списку. Дальше пока ничего: см.
[02-stage-my.md](02-stage-my.md).

## 3. Архитектура: конкурс — потребитель тренажёра

Главное ограничение: тренажёр в проде, им пользуются прямо сейчас. Конкурс не
меняет его поведение для существующих сценариев.

```
┌─ КОНКУРС ──────────────────────────────────┐
│  /cours — уроки, прогресс, гейты           │
│  привязка к профилю портала                │
└───────────────┬────────────────────────────┘
                │  контекст доступа { tokenType, sectionId, taskRange }
┌───────────────▼────────────────────────────┐
│  ТРЕНАЖЁР — как есть                       │
│  legacy-токены · сессии · админка · СОВА   │
└────────────────────────────────────────────┘
```

**Точка стыковки одна:** `resolveMayakTokenContext()` в
[mayakTokenContext.js](../../src/lib/mayakTokenContext.js) получил четвёртую
ветку `tokenType: "contest"` рядом с `legacy`, `session` и `bypass`.

Что делает конкурсный вход:

- «ключом» служит авторизация портала — участнику ничего не выдаётся;
- ключ вида `contest-3` только указывает урок, секретом не является;
- ничего не расходуется: `usedCount` не трогается;
- `sessionId` пустой → конкурсные прохождения не создают сессий и не попадают
  в сессионный дашборд, статистику столов и очередь инспектора.

Ветка срабатывает только на префикс `contest-`. Откат = удалить ветку.

### Конкурсный режим экрана

При заходе из урока тренажёр выглядит иначе:

| Обычный режим | Конкурсный |
|---|---|
| «Завершить сессию» | «Вернуться к урокам» |
| переключатель номеров задач | лесенка из 8 уроков |
| «Выбрать роль» | скрыта — роли относятся к этапу «Мы» |
| история запросов | скрыта |
| материалы по таймеру сессии | доступны сразу |

Режим включается **явно**: переход из списка идёт с меткой `?contest=1` и
ставит флаг в `sessionStorage`. По куке ориентироваться нельзя — она живёт
30 дней, и тогда обычный заход через меню «Маяк Око» тоже открывал бы
конкурсный экран.

## 4. Как заливается контент

Три разных канала, у каждого своё хранилище. Не перепутать.

| Что | Где лежит | Как заливать |
|-----|-----------|--------------|
| Видеоурок | `learning_service`, `courses.download_url` | ссылка на RuTube-embed |
| Название и описание урока | `learning_service`, `courses` | там же |
| Текст задания (цель, шаги, результат) | **код**: [contestTrainerTasks.js](../../src/lib/contestTrainerTasks.js) | временно, переедет в БД |
| PDF задания, инструкция, карта | колода тренажёра: `<sectionId>/Files/<номер>.pdf`, `Instructions/`, `Maps/` | админка МАЯКа `/admin/mayak-content` |
| Ответы участников | `data/contest-answers/` | загружают сами участники |

**PDF класть можно** — механизм в тренажёре есть и работает в боевых колодах:
в `901-1000` лежат 47 файлов вида `910.pdf`, в `8001-8100` — инструкция
`8017.pdf`. Файл именуется номером задачи, привязка автоматическая.

### Видео грузится только по клику

Замер: embed RuTube тянет **~2 МБ своего JS** плюс 271 КБ метрики Яндекса на
каждый вставленный ролик. Восемь уроков — это двадцать мегабайт внешних
запросов. Поэтому до клика показывается обложка, плеер создаётся по нажатию.
Место зарезервировано пропорцией 16/9, подмена не сдвигает вёрстку.

Своей картинки-обложки у уроков пока нет: у RuTube превью не забрать, его API
и oEmbed отвечают 403. В [VideoFacade](../../src/components/ui/VideoFacade.js)
готов проп `poster` — когда появится канал загрузки обложек, достаточно
передать ссылку.

### Пункт 1а: разметка колоды не совпадает с уроками

Проверено 06.08.2026 сверкой `contestTrainerTasks.js` с `contentType` задач
в колоде `1-100`. Семь уроков из восьми открывают задачу не того формата,
которому был посвящён урок:

| Урок | Ждём формат | Что реально открывается |
|---|---|---|
| 1 Вводный | Старт | Старт ×4 ✅ |
| 2 Текст | Текст | Старт, Старт, Текст, Текст |
| 3 Аудио | Аудио | Текст ×4 |
| 4 Изображение | Изображение | Карта настроения, Аудио ×3 |
| 5 Интерактив | Интерактив | Аудио ×3, Карта настроения |
| 6 Видео | Видео | Статика ×4 |
| 7 Данные | Данные | Статика ×2, Карта настроения, Интерактив |
| 8 Итог | Итог | Интерактив ×4 |

Причина: карта нарезает колоду ровными блоками по 4 задачи, а `1-100` — общая
колода тренажёра, форматы в ней идут в своём порядке. Варианты решения
вынесены в открытые вопросы [05-decisions.md](05-decisions.md).
