## Принятые решения

| Дата | Вопрос | Решение | Почему |
|------|--------|---------|--------|
| 05.08.2026 | Где живёт конкурс: свой раздел или существующее «Обучение»? | Существующее «Обучение», пункт меню переименован в «Конкурс» | Два похожих раздела путают участника. В старом лежала одна тестовая заглушка — терять нечего |
| 05.08.2026 | Свой курсовый движок или `learning_service`? | `learning_service` | Уроки, прогресс, сдачи и модерация там уже есть |
| 05.08.2026 | Как конкурс относится к тренажёру? | Конкурс — потребитель, тренажёр не переписывается | Тренажёр в проде. Точка стыковки одна: `tokenType: "contest"` |
| 05.08.2026 | Как участник входит в тренажёр? | По авторизации портала, ключ не выдаётся | Участник уже авторизован; выдавать ключи руками на сотни человек нереально |
| 05.08.2026 | Правило открытия уроков | Линейное: прошёл N → открыт N+1 | Решение владельца продукта; тайминги отложены |
| 05.08.2026 | Нужна ли промежуточная страница урока? | Нет, удалена | Ролик, задание и ответ уже есть в тренажёре |
| 05.08.2026 | Куда ведёт участник после входа? | В «Конкурс», а не в профиль | Пришёл участвовать, а не заполнять анкету. Исключение: пустой профиль → настройки |
| 05.08.2026 | Задание проверяет модератор? | Нет, закрытие сразу | 926 участников × 8 уроков = 7400 ручных проверок |
| 06.08.2026 | Как показывать видео? | Обложка, плеер по клику | Каждый embed RuTube тянет ~2 МБ JS + 271 КБ метрики |
| 06.08.2026 | Конкурс использует колоды тренажёра? | **Нет. Колод и карт в конкурсе не будет** | Другой формат: в тренажёре участник разбирает готовые карточки заданий, в конкурсе — решает задачу из своего урока. Общее — только фреймворк МАЯК ОКО как инструмент |
| 06.08.2026 | Сколько задач на урок? | Одна | Урок = одно задание, участник его решает |
