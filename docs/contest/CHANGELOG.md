## 06.08.2026

- этап «Мы» перестал быть белым пятном: тренажёр в нём не участвует, механика
  берётся из существующего раздела «Проекты» — шесть категорий совпадают
  с направлениями «ЗВЕЗДЫ», задания закреплены за командой, сдача и модерация
  уже есть. Разобрано по коду, записано в `02-stage-my.md`
- решения: команда работает только полным составом 4, только внутри одной
  организации, рейтинг нужен, передача лидерства не нужна, переполненной
  команде показываем заглушку, перепроходить закрытый урок нельзя
- бэкенд: вход в команду только по ссылке-приглашению, гейты «прошёл этап «Я»»
  и «указал организацию», исключение участника лидером, мгновенный `is_learned`
  после последнего урока. Ветка `feat/contest-team-invites` в `../back/RSK_back`,
  локально, на прод не выкатывалось. Попутно исправлен падавший ручной
  пересчёт статуса обучения. Фронта под это пока нет
- ревизия команд по коду `teams_service`: состав 3+1 **уже проверяется** при
  вступлении — прежняя запись в `03-teams-and-orgs.md` об обратном была ошибкой.
  Решено: вход в команду только по ссылке-приглашению, и только для тех, кто
  закрыл этап «Я» и указал организацию; лидеру нужна возможность исключать
- конкурс отвязан от колод: `content-bundle` на префикс `contest-` собирает
  бандл из задания урока вместо чтения колоды с диска. Заодно снято правило
  «оценка недоступна на первых трёх заданиях колоды» — конкурсная задача всегда
  первая, и без этого СОВА была бы закрыта на всех восьми уроках. Проверено
  сквозным прогоном участника на локальном стенде
- решение: остальной экран тренажёра в конкурсе сохраняется целиком — поля
  МАЯК ОКО, промт, нейросети, оценка СОВЫ, ролик. Материалов к заданию, скорее
  всего, не будет. План отвязки от колод описан в `01-stage-ya.md`, §1а
- решение: **в конкурсе колод и карт нет**, задание на урок одно. Расхождение
  форматов, найденное ревизией, чинить не нужно — колода уходит целиком.
  Критерий «задание выполнено» отложен до появления материалов уроков
- ревизия готовности этапа «Я» по факту: сверены карта уроков, колода `1-100`
  и база `rsk_learning`. Найдено расхождение форматов — 7 уроков из 8 открывают
  задачу не того формата (пункт 1а в `01-stage-ya.md`)
- `64d911f` — ролики не грузятся, пока их не открыли: замер показал ~2 МБ JS

- `29bcbac` — материалы задания (PDF, инструкция, карта) доступны в конкурсном
