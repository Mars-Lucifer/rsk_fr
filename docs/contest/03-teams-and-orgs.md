## Задуманный путь

1. участник указывает организацию в настройках профиля;
2. один из участников создаёт команду внутри своей организации;
3. остальные присоединяются к ней;
4. состав — 3 преподавателя + 1 студент.

## Состав 3+1 проверяется бэкендом 🟢

Проверено по коду 06.08.2026. Ранее в этом файле было написано обратное — это
была ошибка. `TeamCRUD.can_user_join_team` вызывается из `join_team`, то есть
правило применяется при самом вступлении, а не только в отдельной ручке:

| Проверка | Что вернёт |
|---|---|
| одна команда на человека | `You already belong to another team` |
| максимум 4 | `Team is full (1 student + 3 teachers)` |
| студент только один | `Team already has a student` |
| преподавателей максимум 3 | `Team already has 3 teachers` |
| место под студента бронируется | `Cannot add teacher - team must have exactly 1 student` |
| прочие роли | `Role '<роль>' cannot join teams` |

Роль берётся из профиля (`Type`) через `UserProfileClient` и приводится
к нижнему регистру. Регистрация ставит ровно `student` («Студент») или
`teacher` («Сотрудник») — значения совпадают, сопоставлять ничего не нужно.

Отдельная ручка `GET /teams/can_join_team/{team_id}` возвращает те же причины
текстом. Фронт её не использует.

Лидер выйти из команды не может: `leave_team` требует сначала передать
лидерство или удалить команду.

Файлы: `teams_service/app/cruds/teams_crud/crud.py`,
`teams_service/app/routes/teams_router/router.py`.

## Сделано в бэкенде 🟢 06.08.2026

Ветка `feat/contest-team-invites` в `../back/RSK_back`. **Локально, на прод
не выкатывалось.**

| Ручка | Что делает |
|---|---|
| `GET /teams/invite_link/{team_id}` | ссылка команды; отдаётся только лидеру |
| `POST /teams/invite_link/{team_id}/regenerate` | перевыпуск; старая ссылка сразу перестаёт работать |
| `GET /teams/invite/{token}` | превью для страницы приглашения: команда, состав, `can_join` и причина |
| `POST /teams/join_by_invite/{token}` | вступление по ссылке |
| `DELETE /teams/remove_member/{team_id}/{user_id}` | исключение участника лидером |

Ссылка одна на команду, срока жизни нет (решение от 06.08.2026). Токен —
колонка `teams.invite_token`, миграция `c1f4a7e2b9d3`; существующим командам
токены проставляются при накатке.

В `can_user_join_team` добавлены два гейта поверх состава 3+1: участник должен
закрыть этап «Я» (`is_learned`) и указать организацию. Чтобы `teams_service`
мог это проверить, batch-ручка `user_profile` теперь отдаёт `is_learned`,
`Organization` и `Organization_id`.

`learning_service` поднимает `is_learned` сразу при закрытии последнего урока —
раньше только почасовая задача. Попутно исправлено: `update_single_user`
и `bulk_update_all_users` звали несуществующий метод клиента и падали.

Прогон на локальном стенде: курс не пройден → «Finish stage «Я»»; курс пройден,
организации нет → «Choose your organization»; всё выполнено → вступил;
битая ссылка → «Invite link is invalid»; участник исключает лидера → 403;
лидер исключает участника → ок; лидер исключает себя → отказ; перевыпуск →
старая ссылка мертва, новая работает.

## Чего не хватает под конкурс ⬜

| # | Что | Где чинить |
|---|-----|-----------|
| 1 | **Фронта под ссылки нет:** лидер её нигде не видит, страницы приглашения не существует, кнопки «Исключить» нет | фронт |
| 2 | Причина отказа не показывается: бэкенд отдаёт текст, фронт его не выводит | фронт |
| 3 | Открытая ручка `join_team/{team_id}` жива — вступить по id всё ещё можно, если знать его. Закрывать после перевода фронта на ссылки | `teams_service` |
| 4 | **Команда не знает про конкурс** — это обычная команда портала, связи с этапами нет | требует решения |
| 5 | Состав 4/4 в интерфейсе никак не подписан — сообщение «Team is full» есть, но по-английски и не выводится | фронт |

## Решения от 06.08.2026

- вступление в команду **только по ссылке-приглашению**: открытого входа быть
  не должно, ссылку рассылает лидер;
- по ссылке пускать только тех, кто **закрыл этап «Я»** и **указал
  организацию**;
- лидер должен уметь **исключать участника** из команды;
- состав 3+1 остаётся как есть — он уже работает.
