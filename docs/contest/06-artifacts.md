# Что сделано: экраны и результаты

Витрина работы по конкурсу — для показа и отчётности. Здесь перечислено, какие
экраны и механики готовы, что именно видит участник и чем это подтверждено.

В отличие от [CHANGELOG.md](CHANGELOG.md), где строки по датам, здесь — по
результату: что можно открыть и показать.

Обновлено: 11.08.2026

---

## 1. Раздел «Конкурс» — список уроков 🟢

**Маршрут:** `/cours`
**Файл:** [src/pages/cours/index.js](../../src/pages/cours/index.js)

Что видит участник:

- заголовок «Конкурс», подзаголовок «Этап «Я»», счётчик «Пройдено N из 8»;
- сетка 4×2 из восьми карточек уроков;
- на каждой карточке: номер, название, формат, обложка видео и статус —
  «Доступен», «Закрыт» или отметка о прохождении;
- открыт только следующий урок, остальные заблокированы;
- у пройденного урока кнопка «Открыть снова».

Проверено: после входа участник попадает сразу сюда, а не в профиль.

## 2. Конкурсный режим тренажёра 🟢

**Маршрут:** `/tools/mayak-oko?contest=1`
**Файлы:** [ContestLessonPanel.js](../../src/components/features/tools-2/ContestLessonPanel.js),
[ContestLessonStepper.js](../../src/components/features/tools-2/ContestLessonStepper.js)

Отличия от обычного тренажёра:

| Обычный режим | Конкурсный |
|---|---|
| «Завершить сессию» | «Вернуться к урокам» |
| переключатель номеров задач | лесенка из 8 уроков в шапке |
| «Выбрать роль» | скрыта |
| история запросов | скрыта |
| материалы по таймеру сессии | доступны сразу |

Что видит участник: лесенку уроков с отметками пройденного, карточку задания
(формат, цель, кнопка «Задание целиком»), видеоурок справа, семь полей
МАЯК ОКО, кнопки «Создать промт» и «Создать промт с оценкой (20/20)», блок
ответа с текстовым полем и загрузкой файла до 20 МБ.

На восьмом уроке дополнительно — кнопка **«Перейти в профиль»**: последний урок
подводит к этапу «Мы», где нужна организация.

**Задание берётся из урока, а не из колоды тренажёра.** Колод и карт
в конкурсе нет — это принципиальное отличие от тренажёрных сессий.

## 3. Прохождение урока 🟢

Механика: «Начать задание» → ответ текстом или файлом → «Завершить задание».
Урок закрывается сразу, без очереди модерации. Повторно сдать нельзя: у
закрытого урока панель показывает «✓ Задание выполнено» и «Следующий урок».

Куда попадают данные:

| Что | Куда |
|---|---|
| ответ участника | `data/contest-answers/` |
| отметка о прохождении | БД `rsk_learning`, таблица `user_progress` |
| флаг «этап «Я» пройден» | профиль, поле `is_learned` |

После восьмого урока `is_learned` поднимается **сразу** и открывает разделы
«Команды» и «Проекты». Раньше это делала почасовая задача, и участник до часа
упирался в закрытые разделы.

## 4. Сборка команды 🟢 бэкенд, 🟢 фронт

### 4.1 Организация в профиле

**Маршрут:** `/profile?tab=settings`

Участник выбирает регион, затем организацию из готового списка. Поле
организации заблокировано, пока не выбран регион. Организации участник не
создаёт — они заведены заранее.

### 4.2 Создание команды

**Маршрут:** `/teams/create`

Лидер вводит только название. Организация и регион подставляются из профиля
и недоступны для правки.

### 4.3 Приглашение — только по ссылке

**Маршрут:** страница команды, блок «Приглашение в команду»
**Виден:** только лидеру

Одна ссылка на команду, срока действия нет. Кнопки «Получить ссылку» и
«Перевыпустить» — после перевыпуска старая ссылка перестаёт работать сразу.
Ссылка копируется в буфер обмена и показывается текстом.

Открытой кнопки «Вступить» на странице команды больше нет: посторонний видит
надпись «Вступить можно только по ссылке-приглашению».

### 4.4 Страница приглашения

**Маршрут:** `/teams/invite/[token]`
**Файл:** [src/pages/teams/invite/[token].js](../../src/pages/teams/invite/[token].js)

Что видит приглашённый: название команды, организацию и регион, состав
(«N из 4: преподавателей N из 3, студентов N из 1») и либо кнопку «Вступить
в команду», либо причину отказа с кнопкой перехода туда, где её можно
устранить — в профиль за организацией или к урокам конкурса.

### 4.5 Правила допуска

Проверяются на бэкенде, действуют на любом пути входа:

| Условие | Текст участнику |
|---|---|
| не закрыт этап «Я» | Сначала завершите этап «Я» — все восемь уроков конкурса |
| нет организации | Сначала выберите организацию в настройках профиля |
| другая организация | Эта команда из другой организации |
| состав 4/4 | Команда переполнена: 3 преподавателя и 1 студент |
| студент уже есть | В команде уже есть студент |
| преподавателей трое | В команде уже трое преподавателей |
| последнее место под студента | Осталось одно место, и оно предназначено студенту |
| уже в другой команде | Вы уже состоите в команде |
| ссылка недействительна | Ссылка недействительна, попросите актуальную |

### 4.6 Исключение участника

В списке состава у лидера — кнопка «Исключить» напротив каждого участника,
кроме себя. Спрашивает подтверждение. Лидер выйти из команды не может: команду
можно только удалить.

## 4.7 Поиск организации в реестре 🟡 ждёт токен

**Маршрут:** `/profile?tab=settings`, блок под списком организаций

Список в базе неполный: на проде 1998 организаций, из них 1670 колледжей, но
это выгрузка, а не весь реестр. Участник из непопавшего колледжа раньше
застревал — без организации не создать команду и не вступить в чужую.

Теперь под списком есть поиск: участник вводит название или ИНН, видит
подсказки из реестра (название, ИНН, регион, пометка «филиал»), выбирает свою —
организация заводится в базе и сразу подставляется в профиль вместе с регионом.

Название, регион и тип берутся из реестра, из формы их подменить нельзя.
Тип определяется по названию: колледж, техникум, училище → «Колледж».
Ликвидированные организации не предлагаются.

**Почему 🟡:** в локальном `.env` вместо токена ДаData стоит заглушка `local`,
реестр отвечает `403 Feature 'SUGGESTIONS' disabled`. Код готов и проверен до
внешнего вызова: прокси отдаёт понятную ошибку, страница профиля собирается.
Нужен настоящий токен — бесплатного тарифа (10 000 подсказок в сутки) хватает
с запасом на тысячу участников.

## 5. Что подтверждено прогонами

**Сквозной путь участника (06.08.2026, локальный стенд):**
регистрация → письмо в MailHog → подтверждение → вход → `/cours` →
урок 1 → заполнение семи полей → промт собран → ответ сохранён →
«Завершить задание» → урок закрыт, следующий открыт → переключение на урок 2
подтянуло его задание. Ошибок в консоли от конкурсного потока нет.

**Правила команды (06.08.2026, два участника — студент и преподаватель):**
курс не пройден → отказ; курс пройден, организации нет → отказ; всё выполнено →
вступил; битая ссылка → отказ; участник исключает лидера → запрещено; лидер
исключает участника → состав уменьшился; лидер исключает себя → запрещено;
перевыпуск ссылки → старая мертва, новая работает.

**Ссылки-приглашения и гейты (11.08.2026, через ручки фронта):**
лидер получил ссылку → превью показало состав и причину → участник другой
организации получил отказ «This team belongs to another organization» и не смог
вступить → лидер исключил участника, состав 2 → 1 → перевыпуск ссылки, старая
сразу перестала работать. Страницы `/teams/invite/[token]`, `/teams/2`
и `/teams` отвечают 200 без ошибок сборки.

Не подтверждено кадром: внешний вид новых экранов — оба браузерных контура
были заняты соседней сессией. Проверено по ответам API и коду разметки.

**Автоматическая проверка:** `node scripts/check-contest-bundle.mjs` — держит
форму задания урока и то, что конкурс не задевает колоды тренажёра.

## 6. Границы: чего в демонстрации нет

Честный список, чтобы не обещать лишнего:

- **контента нет** — на всех восьми уроках один и тот же промо-ролик, тексты
  заданий условные;
- **этап «Мы» не связан с конкурсом** — механика проектов существует, но
  привязки к конкурсу и рейтинга пока нет;
- **на прод не выкатывалось** — всё работает на локальном стенде, ветки
  локальные;
- выполнение задания не проверяется: критерий ещё не определён.

## Правило пополнения

Новый готовый экран или механика — новый раздел здесь, с маршрутом, описанием
того, что видит участник, и строкой о том, чем это подтверждено. Незаконченное
сюда не попадает: этот файл должен оставаться тем, что можно открыть и показать.
