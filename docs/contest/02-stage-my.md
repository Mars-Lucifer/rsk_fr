## Что уже построено в «Проектах»

Проверено по коду `projects_service` и `src/pages/projects/*` 06.08.2026.

**Шесть категорий совпадают с направлениями «ЗВЕЗДЫ»** один в один:

| Код | Название во фронте |
|---|---|
| `KNOWLEDGE` | Знания и навыки |
| `INTERACTION` | Взаимодействие с работодателями |
| `ENVIRONMENT` | Единая цифровая образовательная среда |
| `PROTECTION` | Защита данных |
| `DATA` | Данные и аналитика |
| `AUTOMATION` | Автоматизация |

**Модель данных** (`projects_service/app/db/models/projects.py`):

```
Project (проект)
  ├─ star_category  — одно из шести направлений
  ├─ star_index, level_number — место в звезде и уровень
  ├─ organization_id / organization_name
  └─ Task (задание проекта)
       ├─ prize_points — баллы за выполнение
       ├─ materials — вложения
       ├─ team_id + leader_id — задание закреплено за командой
       ├─ status: NOT_STARTED → IN_PROGRESS → SUBMITTED → ACCEPTED / REJECTED
       └─ TaskSubmission (сдача)
            ├─ text_description, result_url
            └─ moderator_id, reviewed_at — модерация
```

**Ручки** (`projects_service/app/routes/router.py`): создание проектов
и заданий, `tasks/{id}/start`, `tasks/{id}/submit`, очередь модератора
`moderator/tasks` и `moderator/{submission_id}/review`.

**Страницы фронта** уже есть:
`/projects` → `/projects/[category]` → `/projects/[category]/[id_project]`
→ `/projects/[category]/[id_project]/[id_task]` со сдачей и экраном
«отправлено».

То есть путь «команда берёт задание → выполняет → сдаёт → модератор
принимает или возвращает» существует целиком.

**Баллы для рейтинга тоже есть в модели:** `tasks.prize_points`, `teams.points`,
`teams.tasks_completed`, а у организаций — поля `star`, `knowledge_skills_z`
и остальные пять направлений.

## Открытые вопросы

1. **Замены в составе.** Можно ли менять участника после начала этапа?
   Что происходит с уже сданными и принятыми заданиями команды, если состав
   поменялся?
2. **Как считается результат команды** — сумма `prize_points`, средняя оценка
   модератора, скорость, или что-то ещё?
3. **Что получает участник на выходе** — сертификат, место в рейтинге, баллы
   в профиль?
4. **Кто модерирует сдачи** и в какие сроки? Очередь модератора в коде есть,
   но для 926 участников это заметная нагрузка.
5. **Проекты общие или свои у каждой организации?** В модели есть
   `organization_id` — значит можно и так, и так.
