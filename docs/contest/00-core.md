# Ядро конкурса

Единое понятийное поле. Здесь — из чего состоит конкурс, какими словами мы его
описываем, что с чем связано и где что живёт. Отдельные файлы описывают этапы
подробно, этот отвечает на вопрос «как это устроено целиком».

Читать первым после [README.md](README.md).

Обновлено: 06.08.2026

---

## 1. Субъекты

| Кто | Что это | Где хранится |
|---|---|---|
| **Участник** | человек с учётной записью портала: преподаватель или студент СПО | `auth_service` (вход), `user_profile` (ФИО, роль, организация) |
| **Организация** | колледж. Участник её не создаёт, а выбирает из готового списка | `orgs_service` |
| **Команда** | 4 человека одной организации: 3 преподавателя + 1 студент | `teams_service` |
| **Лидер** | тот, кто создал команду. Рассылает ссылку, исключает участников | `teams.leader_id` |

Роль участника (`student` / `teacher`) задаётся при регистрации и лежит
в профиле. Состав команды проверяется по ней — отдельного поля роли
в команде нет и не нужно.

## 2. Два этапа

Порядок жёсткий: сначала «Я», потом «Мы».

| | Этап «Я» | Этап «Мы» |
|---|---|---|
| Субъект | один участник | команда из 4 |
| Содержание | 8 видеоуроков, к каждому задание | проекты по направлениям «ЗВЕЗДЫ» |
| Инструмент | тренажёр МАЯК ОКО | тренажёр **не участвует** |
| Где живёт | `learning_service` + тренажёр | `projects_service` |
| Статус | 🟢 собран, ждёт контента | 🟡 механика есть, под конкурс не связана |

Переход между этапами — флаг `is_learned` в профиле. Он поднимается, когда
закрыты все 8 уроков, и открывает разделы «Команды» и «Проекты».

## 3. Словарь

Термины, которые легко перепутать. Пользуемся только этими значениями.

**Урок** — одна из восьми единиц этапа «Я»: видео + задание + приём ответа.
Хранится в `learning_service`, таблица `courses`, ключ — `lesson_number`.

**Задание урока** — текст: цель, шаги, результат. Одно на урок. Сейчас лежит
в коде (`src/lib/contestTrainerTasks.js`), потом переедет в БД.

**Ответ** — то, что участник сдал: текст или файл до 20 МБ. Лежит в
`data/contest-answers/`, не в БД.

**Колода** — набор карточек заданий тренажёра (`1-100`, `901-1000` и т. д.).
**В конкурсе колод нет.** Слово употребляем только про тренажёрные сессии.

**Фреймворк МАЯК ОКО** — семь полей, из которых собирается промт. Это
инструмент, общий у конкурса и тренажёра. В конкурсе остаётся.

**СОВА** — оценка промта, до 20 баллов. В конкурсе остаётся.

**ЗВЕЗДА** — модель из шести направлений. Одни и те же шесть встречаются
в трёх местах и означают одно и то же:

| Код в `projects_service` | Название | Поле в `organizations` |
|---|---|---|
| `KNOWLEDGE` | Знания и навыки | `knowledge_skills_z` / `_v` |
| `INTERACTION` | Взаимодействие с работодателями | — |
| `ENVIRONMENT` | Единая цифровая образовательная среда | `digital_env_e` |
| `PROTECTION` | Защита данных | `data_protection_z` |
| `DATA` | Данные и аналитика | `data_analytics_d` |
| `AUTOMATION` | Автоматизация | `automation_a` |

**Проект** — единица этапа «Мы»: относится к одному направлению звезды,
имеет уровень и организацию, содержит задания.

**Задание проекта** — то, что выполняет команда. Закреплено за `team_id`,
даёт баллы (`prize_points`), проходит статусы
`не начато → в работе → сдано → принято / возвращено`.

**Сдача** — результат команды по заданию проекта: текст и ссылка. Проверяет
модератор.

**Ссылка-приглашение** — единственный правильный вход в команду. Одна
на команду, без срока, лидер может перевыпустить.

## 4. Путь участника целиком

```
регистрация ──> подтверждение почты ──> вход
                                          │
                                          ▼
                            /cours — восемь уроков
                                          │
        урок открыт только следующий, предыдущий закрыт
                                          │
                                          ▼
                тренажёр ?contest=1 — задание урока
                фреймворк МАЯК ОКО, промт, СОВА, нейросети
                                          │
                             ответ: текст или файл
                                          │
                              «Завершить задание»
                                          │
                        ┌─────────────────┴──────────────┐
                        │ уроков осталось                │ закрыт последний
                        ▼                                ▼
                 следующий урок              is_learned = true
                                                         │
                                    открываются «Команды» и «Проекты»
                                                         │
                          ┌──────────────────────────────┴────────┐
                          ▼                                       ▼
              указать организацию                    лидер создаёт команду
                   в профиле                          и рассылает ссылку
                          └──────────────────┬────────────────────┘
                                             ▼
                              вступление по ссылке-приглашению
                                  (гейты: этап «Я», организация,
                                   состав 3+1, одна команда на человека)
                                             │
                                    команда из 4 человек
                                             │
                                             ▼
                          этап «Мы»: проекты по направлениям ЗВЕЗДЫ
                          задание → выполнение → сдача → модерация
                                             │
                                             ▼
                                    баллы, рейтинг
```

## 5. Правила и гейты

Всё, что кого-то куда-то не пускает. Один список, чтобы не искать по файлам.

| Гейт | Правило | Где проверяется |
|---|---|---|
| Открытие уроков | следующий урок доступен, когда закрыт предыдущий | фронт + `learning_service` |
| Повторная сдача | закрытый урок можно открыть, но сдать повторно нельзя | ⬜ не реализовано |
| Вход в тренажёр из конкурса | достаточно авторизации портала, ключ не выдаётся | `mayakContestAccess.js` |
| Вход в команду | только по ссылке-приглашению | `join_by_invite` ✅ |
| Допуск в команду | закрыт этап «Я» (`is_learned`) | `can_user_join_team` ✅ |
| Допуск в команду | указана организация | `can_user_join_team` ✅ |
| Допуск в команду | та же организация, что у команды | ⬜ не реализовано |
| Состав | максимум 4: 1 студент + 3 преподавателя | `can_user_join_team` ✅ |
| Состав | одна команда на человека | `can_user_join_team` ✅ |
| Исключение | только лидер, себя исключить нельзя | `remove_member` ✅ |
| Выход лидера | запрещён, передачи лидерства не будет | `leave_team` ✅ |
| Работа над проектами | только полным составом 4 | ⬜ не реализовано |

✅ — сделано и проверено локально. ⬜ — решено, но не написано.

## 6. Кто чем владеет

Правило: **чинить в том сервисе, которому принадлежит контракт.** Фронт
`rsk_fr` — оболочка и прокси, бизнес-логика живёт в `../back/RSK_back`.

| Что | Сервис | Порт | Что от него зависит в конкурсе |
|---|---|---|---|
| вход, регистрация, подтверждение почты | `auth_service` | 8002 | доступ участника |
| ФИО, роль, организация, `is_learned` | `user_profile` | 8003 | состав 3+1, гейты команды |
| команды, состав, приглашения | `teams_service` | 8004 | весь путь сборки команды |
| справочник организаций | `orgs_service` | 8005 | выбор организации |
| проекты, задания, сдачи, модерация | `projects_service` | 8010 | этап «Мы» |
| уроки и прогресс | `learning_service` | 8011 | этап «Я», флаг `is_learned` |

На фронте конкурс — это `/cours`, конкурсный режим тренажёра
(`?contest=1`) и прокси-ручки `src/pages/api/*`.

## 8. Как пополнять этот файл

Ядро описывает **устройство**, а не задачи и не историю. Сюда попадает:

- новое понятие, которым мы начали пользоваться, — в словарь;
- новый гейт или правило — в таблицу правил;
- изменение потока участника — в схему;
- перенос ответственности между сервисами — в таблицу владения.

Сюда **не** попадает: список задач, статусы готовности отдельных пунктов,
причины решений. Для них есть файлы этапов и журнал решений.

Если при работе возник вопрос «а как это вообще связано» — ответ должен
появиться здесь, иначе он будет задан ещё раз.
