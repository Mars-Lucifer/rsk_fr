## Шаг 2. Проверить, что вы там, где думаете

```bash
git branch --show-current
git status --short
```

Если в копии лежат чужие незакоммиченные файлы — **остановиться и сказать
об этом**. Не коммитить вокруг них, не переключать ветку под ними.

## Шаг 3. Поднять стенд

Бэкенд общий для всех копий, поднимается один раз:

```bash
cd "C:/Disk D/Project/back/RSK_back"
docker compose -f docker-compose.override.yml -f docker-compose.local.yml up -d
```

Проверка, что живой: `curl http://localhost:8081/teams/teams/all_teams/`

Дев-сервер — свой на каждую копию, порты разные, иначе сессии выбивают
друг друга:

| Копия | Порт |
|---|---|
| `.worktrees/contest` | 1241 |
| `rsk_fr-main` | 1234 |
| `.worktrees/mayak-master` | 1235 |
| `.worktrees/mayak-guide` | 1237 |
| `.worktrees/conferencia` | 1240 |

```bash
npm --prefix <каталог> run dev -- -p <порт>
```

## Мины, на которых уже спотыкались

**Шлюз слушает 8081, а не 8080.** Порт 8080 занял MCP-сервер Figma. Адрес
задан в `.env.local` каждой копии переменными `RSK_API_BASE`
и `NEXT_PUBLIC_RSK_API_BASE`. Если страница профиля висит на «Загружаем
профиль...» — почти наверняка в этой копии остался старый порт.

**`.env.local` и `node_modules` не переносятся между копиями.** Они
в `.gitignore`, новый worktree создаётся без них: нужно скопировать
`.env.local` из основной копии и выполнить `npm install`.

**Письма подтверждения ведут на `:8080`.** Адрес зашит в настройках
`auth_service`. При локальной проверке порт в ссылке правится руками.

**Контейнеры БД иногда стоят.** Проверять `docker ps -a`: у нас база
организаций простояла три дня, и это выглядело как поломка сети.

**Ветка может уехать под вами.** Основная копия несколько раз оказывалась
на чужой ветке — соседняя сессия переключала её. Именно поэтому у конкурса
теперь своя папка: git не даёт двум папкам держать одну ветку, и переключить
нашу из чужого каталога нельзя. Перед первым коммитом всё равно
`git branch --show-current`.

## Как начать новый чат

Скажите ассистенту одной фразой:

> Работаем над <направление>. Копия — <каталог>, ветка — <ветка>.
> Прочитай `docs/WORKSTREAMS.md` и `docs/contest/README.md`.

Этого достаточно, чтобы он не начал править чужие файлы и не полез
в основную копию, когда там работает другая сессия.
