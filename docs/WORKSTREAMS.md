# С чего начать работу

Обновлено: 12.08.2026

## Живая карта переехала

Карта направлений, ветки, порты и состояние стенда живут в глобальном
`~/.claude/CLAUDE.md`, раздел «rsk_fr: карта направлений».

Почему не здесь: этот файл версионируется, то есть у каждой ветки своя копия.
Карта веток, которая зависит от того, в какой ты ветке, — не карта. До 12.08.2026
она расходилась между `feat/contest-stage-ya` и остальными, а сам `CLAUDE.md`
конфликтовал в 6 парах слияния из 21 ровно по этой причине.

Правила веток — там же, раздел «Ветки и коммиты». Архитектура репозитория —
в [CLAUDE.md](../CLAUDE.md).

## Что осталось верным здесь

**Рабочая копия одна:** `C:\Disk D\Project\rsk_fr-main`. Постоянные worktree
не заводятся, переключение ветками через `git switch`.

**Перед первым изменением:**

```bash
git branch --show-current
git status --untracked-files=all
```

Второй флаг обязателен: обычный `status` сворачивает неотслеживаемые файлы,
и рядом с правками легко не заметить несохранённые скрипты проверок.

**Контейнеры БД иногда стоят.** Проверять `docker ps -a`: база организаций
однажды простояла три дня, и это выглядело как поломка сети.
