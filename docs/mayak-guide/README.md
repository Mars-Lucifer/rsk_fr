# Гайд мастера

Контекст направления. Живёт в ветке `feat/mayak-guide` и правится **только
отсюда** — это единственный владелец файлов гайда.

Обновлено: 12.08.2026

## Что это

Публичная страница `/mayak-guide` — руководство, по которому мастер ведёт
сессию МАЯКа. Открывается из консоли доступа мастера в новой вкладке. Данных
сессии внутри нет, только правила и разбор поля.

Плюс `/mayak-guide-3d` — стол мастера в 3D: сцена с полем, колодами, жетонами,
фишками и ноутбуком.

## Файлы направления

```
src/pages/mayak-guide.js                      страница руководства
src/pages/mayak-guide-3d.js                   стол в 3D
src/pages/mayak-3d/{field,jetons,roles}.js    отдельные сцены
src/components/features/mayak-guide/*         компоненты и данные
```

**Эти файлы не правятся из других веток.** Правило исполняется хуком
`~/.claude/hooks/guard-mayak-guide.mjs`: правка из ветки вне `feat/mayak-guide*`
блокируется с объяснением. Причина — 12.08.2026 выяснилось, что гайд писали
параллельно в четырёх ветках, и он давал 19 конфликтов из 21 пары.

## Как проверять

Кадром, не чтением кода. У страницы и особенно у 3D-стола числа камеры,
раскрытия и раскладки калибровочные — по исходнику не видно, правильно ли
получилось.

Снимать через MCP `playwright` (свой headless-браузер), а не через
preview-панель харнесса: свёрнутая панель не композитит кадры, страница
выглядит пустой, и это легко принять за поломку.

## Что уже решено

**Вёрстка раздела ролей** (12.08.2026, коммиты `65df053`, `fbb39a2`).
Перенесена из ветки контура доступа, где была написана 6 августа и осталась
заперта. Заголовок одной строкой, роль описана списком коротких строк,
стрелки под лентой по центру, отступы секции сжаты `64/76 → 34/40`.

Побочный эффект сжатых отступов: заголовок уезжал под липкую шапку при
переходе по якорю. Держится `scroll-margin-top: 92px` по высоте шапки (85 px).

**Правила игры сверяются по проду**, а не по свежести коммита.
`root@91.228.225.182:/root/rsk_fr` — там зафиксирована актуальная версия.
Проверено 12.08.2026: внешний круг карт не выдаёт («карт здесь не берут»).

**Разбор карты задания.** Габариты элементов лежат в `cardPins.mjs` полем
`box` рядом с точкой: на 3D-столе элемент обводят рамкой и ставят номер у
кромки блока, вместо точки посреди текста.
