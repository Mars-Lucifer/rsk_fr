# Конференция

Контекст направления. Живёт в ветке `feat/conferencia` и правится **только
отсюда**.

Обновлено: 12.08.2026

## Что это

Протокол отбора делегатов от региональных отделений: страница собрания,
загрузка документов, админка для разбора поступивших протоколов.

## Файлы направления

```
src/pages/conferencia/{index,admin,[id]}.js
src/pages/api/conferencia/*
src/components/rosdk-confrencia/*
src/lib/rosdk-confrencia/*
```

Направление ни с кем не пересекается по страницам — единственное из пяти,
которое сливалось с `main` начисто с самого начала.

## Данные

Отправки участников лежат в `data/uploads/<uuid>/` и в `data/rsk.sqlite`.
Оба пути в `.gitignore` и **нигде не дублируются** — ни в репозитории, ни на
сервере. Потеря локальных файлов означает потерю отправок.

12.08.2026 пять папок загрузок нашлись только в отдельной рабочей копии этой
ветки и были сведены в общий каталог. Копий больше нет, работа идёт в одной
папке — риск снят, но правило прежнее: `data/` не коммитить и не удалять
без проверки.

## История

До 10.08.2026 работа велась в ветке, отведённой от конкурсной, — при слиянии
в `main` уехал бы и весь недоделанный конкурс. Направления разведены,
ветка отведена от `main`.

Старые имена той же линии (`feat/conferencia-ro-package`,
`chore/portal-api-base`) — не это направление, а ранние снимки конкурсной
линии. Работа из них целиком внутри `feat/concurs`.

## Открытое

Два стэша с ранней версией конференции помечены тегами
`backup/stash-0-conferencia-sources` и `backup/stash-1-conferencia-wip`.
Содержимое старше текущей ветки — разобрать или отпустить.
