# ЗВЕЗДА-6 и 3D-реквизит

Контекст направления. Живёт в ветке `feat/mayak-zvezda` и правится **только
отсюда**.

Обновлено: 12.08.2026

## Что это

Объяснялка модели ЗВЕЗДА-6 — шесть направлений цифровой зрелости, по которым
команда идёт на этапе «МЫ». История уровня показывается кадрами и в 3D.

Ответвление от `feat/mayak-guide`: общий 3D-стол взят оттуда, здесь надстроены
свои сцены и эффекты.

## Файлы направления

```
src/pages/zvezda-3d.js       сцена ЗВЕЗДА-6
src/pages/zvezda-room.js     комната
```

Общие с гайдом файлы (`src/components/features/mayak-guide/*`,
`src/pages/mayak-guide.js`) — **не свои**. Их владелец `feat/mayak-guide`,
правка отсюда блокируется хуком. Если нужна правка гайда — переключиться
на его ветку.

## Свои зависимости

Кроме общего набора 3D, здесь стоят два пакета для эффектов:

```
@react-three/postprocessing
postprocessing
```

Их нет в `main` и в других ветках. После слияния `main` в эту ветку
`package.json` берётся отсюда (надмножество), затем обязательно `npm install` —
иначе сборка упадёт с «Cannot resolve», и это будет выглядеть как поломка кода,
хотя дело только в устаревшем `node_modules`.

## Как проверять

Кадром через MCP `playwright`, не чтением кода: камера, свет и раскладка
калибруются по картинке. Preview-панель харнесса для 3D не годится, пока она
свёрнута — кадры не композитятся, сцена выглядит пустой.
